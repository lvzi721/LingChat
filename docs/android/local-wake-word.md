# Android 锁屏本地唤醒词

当前实现的目标是：

> 用户手动开启一次“锁屏本地唤醒”后，只要 LingChat 前台服务没有被系统清理，就可以在锁屏状态下用设备端语音识别监听唤醒词并呼出 LingChat。

## 行为边界

- 使用 Android `SpeechRecognizer` 的 `createOnDeviceSpeechRecognizer`，不会回退到云端识别。
- 设备必须提供设备端语音识别服务；不支持时设置页会显示“不支持”，不会静默使用网络识别。
- 服务由用户从设置页主动启动。Android 14 以后，麦克风前台服务不能在后台任意冷启动。
- 华为等厂商清理进程、强制停止应用或重启设备后，服务会停止；需要重新打开 LingChat 恢复。
- 唤醒词匹配在设备端完成，支持在设置页修改。当前使用自由文本短语，不做声纹验证。

## 权限与厂商设置

首次开启需要：

- 麦克风权限
- 通知权限（Android 13+）
- 常驻前台通知
- 华为应用启动管理中的自启动、关联启动、后台活动

设置页提供“请求权限”和“系统后台设置”入口。

## 与现有 ASR 的关系

唤醒词检测由 Android 原生前台服务负责，普通对话 ASR 仍使用 LingChat 现有录音和 provider 链路。出现以下情况时，原生服务会暂停，避免两个录音链路争抢麦克风：

- 普通按钮/自动 ASR 开始录音
- TTS 正在播放
- 唤醒词触发后，前端接管新一轮命令录音

会话结束后，服务会在没有 TTS 播放时恢复监听。

## 验证清单

1. 打开设置页，进入“语音识别”。
2. 请求麦克风/通知权限并授予。
3. 设置唤醒词并保存。
4. 开启“锁屏本地唤醒”，确认前台服务显示为运行中。
5. 锁屏并息屏，说出唤醒词。
6. 确认耳机/扬声器旁出现 LingChat 的语音输入流程。
7. 分别在普通使用、TTS 播放、切到后台、重启设备后测试服务恢复行为。
